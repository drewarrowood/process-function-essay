Unique finish, written as a temporal formula

Draft. Not submitted. The claim is a condition on one step, not a metric.

Abstract

A time-travel story fails in two ways. No version fits, or more than one version fits. Philosophers answered by changing the meaning of can, or by discarding the bad histories. This note writes the sharper rule in the language of temporal logic. A state is the string that was sent. A process returns a string. An intervention is a local rule. The one step is agreement after the return. A process is admitted only when every intervention has exactly one state that agrees. The open shuffle that records the step is a bijection for every process. Closing the step is not. The copy rule has eight agreeing states on three people.

1. The formula

Let \(o\) be a string of bits, one per party. Let \(w\) send that string to the string received. Let \(f\) be a local rule from a received bit to a sent bit. Write

\[ \mathrm{Fix}(w,f,o) \iff \forall k.\; o_k = f_k(w_k(o)). \]

The process-function clause is

\[ \mathrm{Process}(w) \iff \forall f.\; \exists!\, o.\; \mathrm{Fix}(w,f,o). \]

In a finite set of strings this is the content of always exactly one finish. It is not a path quantifier over a curve. The grandfather case is \(\forall o.\, \neg\mathrm{Fix}(w,f,o)\). The note in the coat is two distinct states that both satisfy Fix. Either refutes Process.

2. Two literatures

Temporal logic began as a reading of tense, not of computation. Prior's tense operators were a formalization of before and after [1]. Pnueli proposed linear temporal logic as a language for programs: always, eventually, until [2]. Clarke and Emerson gave the branching version, CTL, with path quantifiers over a computation tree [3]. The formula above uses none of the path quantifiers. Exists-unique is a first-order condition on one transition. Calling it temporal records what the transition is: the story after the return must agree with the story that was sent.

The other literature is about which stories are kept. Dummett treated the ban as a rule of English [4]. Lewis split can into a local and a global reading [5]. Godel gave a rotating dust solution with a closed curve through every event [6]. Morris, Thorne and Yurtsever made a wormhole into a time machine if the averaged null energy condition fails [7]. The billiard has data with one continuation, two, or none [8]. Novikov's principle keeps the consistent data and assigns the rest measure zero [9]. Earman: a selection rule is not a dynamics [10]. Deutsch asks for a fixed point of a state on the curve [11]. Lloyd and Maccone post-select the matching runs [12]. Oreshkov, Costa and Brukner write a channel from outputs to inputs with no assumed order [13]. Baumeler, Costa, Ralph, Wolf and Zych define the process function and extend it by a source and a sink [14]. Ori's dust shell is a compact vacuum core that develops closed curves; it is not this formula [15].

3. The open shuffle

Add a source \(e\) and store the sent string. Define

\[ U(o,e) = (w(o)\oplus e,\, o), \qquad U^{-1}(i,s) = (s,\, w(s)\oplus i). \]

Both compositions are the identity because \(a\oplus(a\oplus b)=b\). This holds for every \(w\), including the copy rule and the swap. Recovery of \(w\) at source 0 is not uniqueness of the fixed point. The Lean file records both compositions as extend_left_inv and extend_right_inv.

4. The closed step

Feeding the output back in, against the identity intervention, asks which strings equal their image. For the copy rule every string does. On three bits the filter has length 8. A witness can kill an off-diagonal of the closed contraction. It cannot make this diagonal equal to 1. Unique finish is what removes the extra count: if two strings differ, some party sent different bits and received the same bit, and that party is a zero factor.

5. What is not claimed

No line element is constructed. CTL path quantifiers are not used. The 2026 note of Daher Ahmed and Kunjwal gives two sufficient conditions, mutual exclusivity and unambiguity, and is not a premise here [16]. Routed quantum circuits are Vanrietvelde, Kristjansson and Barrett; Ormrod is not an author [17].
