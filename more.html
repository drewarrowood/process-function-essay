Earlier explanation

Four processes, eight strings, one witness

One bit, all four rules

A single desk has four processes from a bit to a bit. Constant 0 always returns 0. Constant 1 always returns 1. Copy returns what was sent. Flip returns the opposite.

Against the identity intervention, which writes what it is shown, constant 0 finishes only if the desk sent 0. Constant 1 finishes only if the desk sent 1. Copy finishes both. Flip finishes neither. So copy is too many, and flip is none, against this one intervention. A process function has to pass every intervention, not the easy one. The open shuffle does not care. For each of the four rules, hiding the bit under a spare bit and storing the sent bit can be undone, because adding a bit twice cancels.

U(o, e) = (w(o) xor e, o). Both compositions are the identity for every w.

The eight strings

Three desks, the copy rule, the intervention that writes what it is shown. Every string agrees with its image. The list is 000, 001, 010, 011, 100, 101, 110, 111. That is eight, not one. Eight is 2 to the number of desks. A good map would have one consistent afternoon. The copy rule has a consistent afternoon for every possible message. Closing the loop did not pick among them.

The witness, without the induction

Take two of those strings that differ, say 000 and 001. They differ at the third desk. If a process shows both the same bit at that desk, the third desk wrote different letters and was shown the same letter. An orthonormal row has inner product zero between different columns. That desk is a zero in the product. The extra afternoon cancels. The witness can be the first desk instead. The argument does not need the difference to sit in a special place. Drop the orthonormal rows and the zero is no longer forced. That is why the cancellation is a theorem about the closed contraction of a process function, and not a theorem about every rule.

The temporal file does not contain this zero. It contains the empty preimage, the two finishes, both compositions of the shuffle, and the eight-count. The gram cancellation is the longer essay. This page only says what the zero is doing.
