What would make it false

The open claim fails only if a spare string does not come back. XOR twice is the bit, so that claim does not fail. The closed claim fails if some three-bit string of the copy rule disagrees with the rule that writes what it is shown. The list is 000, 001, 010, 011, 100, 101, 110, 111, and each agrees. A discovered line element would not make either claim false. It would be a realization, which is not asserted.

Open column, closed diagonal

Fix the spare at zero and the open map stores what was sent in the second slot. Different strings stay apart. That is an isometry of the recorded string, and the copy rule has it. Closing the loop throws the slot away. The closed diagonal then has eight terms. The spare page still comes back on the day the loop is locked, and on the day every slip is accepted. The eight slips are not one slip.

Open: U(o, 0) = (w(o), o). Closed, identity intervention, copy rule: eight fixed strings.

Where a reader can stop

Stop after the spare-bit walk-through if the question is whether the record can be undone. Stop after the list of eight if the question is whether closing the loop picks one afternoon. Stop after the witness if the question is why a process function cancels the extras. Do not stop at a metric. None is constructed. The temporal file stops at the inverse and the eight. The zero in the product is the longer essay.
