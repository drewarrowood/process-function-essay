The list of desks

List the parties. If two strings differ at the first and the process agrees there, the first factor is zero. If not, the same argument applies to the rest of the list. A zero anywhere is enough. The induction does not prefer a named party. That is why the witness can sit at the last desk. Drop the orthonormal rows and the factor is not forced to be zero. The temporal file does not contain this list argument. It contains the inverse and the eight-count.

Differ at some desk, same received bit there, orthonormal row: that factor is 0, so the term is 0.

What post-selection does not do

Lloyd and Maccone discard runs that do not match. The map remains. A process function discards the map, before a sample, if any intervention has no finish or two. Deutsch solves for a state and finds one, so the grandfather interaction is not forbidden. The process function forbids it, written as a rule with no finish. Neither condition needs a curve as a premise. A curve is a picture of where the map might sit. The picture is not the map.

No new theorem

The expansion is explanation. The open inverse holds for every rule, because XOR twice is the bit. The closed copy rule has eight finishes on three bits, the list 000 through 111. Under orthonormal rows, the witness is a zero. No metric was defined. The temporal file still does not contain the gram identity. A larger alphabet is a shape, not a theorem of the file.
