Unique finish, at more length

Equations are text, so they show if a script does not run. This is an explanation, not a metric.

The office

Three desks share an afternoon. Each desk sends a bit and is shown a bit. The process is the rule that turns what was sent into what is shown. A local rule is what a desk does with the bit it is shown: copy it, flip it, or ignore it and write 0 or 1. The afternoon finishes when the bits that were sent are the bits the desks would write after seeing what came back.

Fix(w, f, o) means: for every desk k, o_k = f_k(w_k(o)).

Process(w) means: for every choice of local rules f, exactly one string o satisfies Fix.

No finish is the grandfather case. She writes the opposite of whatever arrived, and no page can be both the thing she received and the opposite of the thing she would send. Two finishes are the note in the coat. A blank page and a page of ink both complete the same errand. Nothing in the office picks which one happened.

One desk, written out

One desk, two bits. The copy rule returns whatever was sent. Against the identity rule, which writes what it is shown, both bits finish. Send 0, receive 0, write 0. Send 1, receive 1, write 1. Two finishes, so the copy rule is not a process function. The flip rule returns the opposite. Against identity, neither bit finishes. Against the flip intervention, exactly one bit finishes for each choice, but the condition has to hold for every intervention, not for the one that works. A process function is a rule that survives every local choice, once.

Three desks

The copy rule on three desks, against identity, finishes every string. There are eight strings. A good map would have one consistent afternoon. Eight is 2 to the number of desks. That number is the diagonal of the identity loop. A disagreement can kill an off-diagonal, where two strings differ and some desk was shown the same bit. It cannot make this diagonal equal to 1. Unique finish is the extra premise that removes the seven extra afternoons.

The spare page

Add a spare page nobody chose, and a copy of what was sent. Hide the afternoon under the spare page by adding the spare bits, and store the sent page in the copy. Run it backwards by reading the copy and adding the process of that copy to the other page. Both ways return the start, because adding a bit twice cancels. This works for every rule, including the copy rule and the swap. Nothing has been fed back. Recovery of the rule at source zero is not uniqueness of the fixed point.

U(o, e) = (w(o) xor e, o). The reverse is (s, w(s) xor i).

Two literatures, more slowly

Lewis says she can prevent the trip, because a small change of her hand would have done it, and she cannot, because the afternoon that occurs is one in which she does not. That splits a word. It does not say which afternoons occur. Novikov keeps the consistent data and assigns the rest measure zero. Earman: a selection rule is not a dynamics. The process-function rule is a condition on the map.

Pnueli's always and eventually are about runs of a program. Emerson and Clarke quantify over paths. The formula here does not. It says the equation of agreement has one solution. Godel, the wormhole, and Ori's dust shell ask whether a curve can close. Dust follows geodesics. It does not evaluate two bits and return a third. A curve would still need a scattering rule. None of the named metrics has been shown to have the three-bit example as that rule.

Deutsch mixes the fixed points of a state. The process function refuses the mix. Lloyd and Maccone throw away the runs that do not match. The process function never generates them. The source and the sink in Baumeler, Costa, Ralph, Wolf and Zych are the spare page and the copy.
