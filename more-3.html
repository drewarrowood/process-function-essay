Four cases, then a product

Why one bit is not enough

On one bit there are four functions. Constant 0 always returns 0. Constant 1 always returns 1. Copy returns the bit. Flip returns the opposite.

A constant cannot answer a rule that demands the bit it never returns. If the desk writes the opposite of what it is shown, constant 0 is shown 0 and must write 1, but it sent 0. Constant 1 fails the same way on the other bit. Copy, against the rule that writes what it is shown, fixes both strings. Flip, against that same rule, fixes neither. So on one bit, none of the four is a process. A process needs more than one party before the count can be one for every local rule. The one-bit case is where the two failures are visible: too many, and none.

How a product becomes an entry

The closed contraction sums, over sent strings, a product over desks. Each desk contributes the overlap of its row at the bit it was shown. If two strings differ at a desk, and the process shows both the same bit there, that desk contributes the inner product of two different columns. An orthonormal row makes that inner product zero. A zero anywhere in the product is a zero of the term. The sum loses that term. That is the witness. It can sit at any desk. The temporal file does not record this product. It records the preimage, the open inverse, and the eight-count.

Disagree at desk k, same received bit at k, orthonormal row: that factor is 0, so the term is 0.

What is refused

A metric that realized the three-bit function would have to carry a scattering rule and still satisfy the field equation. None of the named solutions does that. Godel's dust, the wormhole, and Ori's shell close a curve. They do not evaluate the fixed-point equation. The open shuffle is not that curve. It is a bijection of bit strings. The closed count of eight is the control, not a line element.
