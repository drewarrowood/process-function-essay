Process functions as a temporal uniqueness condition

Draft. Equations are written as HTML so they show in Facebook’s browser, which does not run MathJax.

Proved: every process finishes once; an empty preimage and a double preimage each refute that; the open shuffle is a bijection for every rule; the closed copy rule has 8 finishes on three bits. Not proved here: the gram cancellation, and any Einstein metric.

The one step

A state o is the string that was sent. w(o) is the string returned. f is the local rule.

Fix(w, f, o)   means   for every party k,   ok = fk(wk(o)).

In next-time notation that is o = f(Xo), with Xo = w(o). There is no further next.

Process(w)   means   for every intervention f, there is exactly one o with Fix(w, f, o).

That is not Pnueli’s “always,” and it is not a path quantifier. The quantifier runs over interventions, not over times.

The two failures

No finish:   for every o,   not Fix(w, f, o).
Two finishes:   there are o and p, o ≠ p, and both fix.

The first is the grandfather case. The second is the note in the coat. Each refutes Process(w).

The open shuffle is not a tense

U(o, e) = (w(o) xor e,   o)
U inverse (i, s) = (s,   w(s) xor i)

Both compositions are the identity for every w, because a xor (a xor b) = b. The copy rule has this bijection and is not a process.

Closing the loop

Against the identity intervention, the copy rule w(o) = o finishes for every string. On three bits that is 8 finishes, not 1. The open bijection does not cancel the extra seven.
