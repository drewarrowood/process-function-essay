How to read the files

Open the temporal file for the preimage, the inverse, and the eight-count. Open the integer file for the product. Open the boundary file for diagonal 8 and the open column at source zero. Open the complex file only for conjugation. If a theorem is not among those names, it is not in that file. The public pages more.html through more-10.html are explanations. They are not the proofs.

What the diagonal is not

The diagonal is the number of admitted strings, once each row has length 1. It is not a curvature, a proper time, or a probability. On one bit the copy rule has diagonal 2, and the flip against the rule that writes what it is shown has diagonal 0. The open inverse holds for both. Three bits is the same separation, with 8 in place of 2.

One bit, copy rule, identity intervention: diagonal 2. Flip: diagonal 0. Open inverse: both.

Not synonyms

A path quantifier, a fixed-point count, a selection on initial data, a filter on samples, and a fixed point of a partial trace are not synonyms. The essay uses the second. Further pages can say the same three numbers more slowly. They should not add a line element. The fifth author in 1995 is H. H. Soleng. Ormrod is not an author of the routed-circuit paper.
