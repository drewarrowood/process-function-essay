Every process function lifts, written as a temporal formula

Draft. This page joins the lift essay and the temporal note. It does not construct a metric.

Abstract

A time-travel story fails in two ways. No version fits, or more than one version fits. The first is the grandfather case. The second is the note that writes itself. Philosophers answered by changing the meaning of can, or by discarding the bad histories. Physicists answered with a curve, and then with a selection rule on the solutions of the curve. This note writes the sharper rule once, in the language of one temporal step, and then records the two maps that step does and does not justify.

A state is the string that was sent. A process returns a string. An intervention is a local rule. Agreement after the return is the only temporal atom. A process is admitted only when every intervention has exactly one agreeing state. Adding a spare input and a copy of what was sent makes a reversible record of any rule, including the bad ones. Feeding the output back in does not. The copy rule has eight agreeing states on three people.

1. The two failures

The telegraph office closed at six. She wrote the opposite of whatever had arrived, and no page could be both the thing she received and the opposite of the thing she would send. That is an afternoon with no finish. The note in the coat has two: a blank page and a page of ink both complete.

Neither is answered by saying the bad afternoon is rare. The first has an empty preimage. The second has two elements in the preimage.

2. The formula

Let \(o\) be a string of bits. Let \(w\) send that string to the string received. Let \(f\) be a local rule. Write

\[ \mathrm{Fix}(w,f,o) \iff \forall k.\; o_k = f_k(w_k(o)). \]

The process-function clause of Baumeler, Costa, Ralph, Wolf and Zych is

\[ \mathrm{Process}(w) \iff \forall f.\; \exists!\, o.\; \mathrm{Fix}(w,f,o). \]

On a finite set of strings this is the content of always exactly one finish. It is not Pnueli's always and eventually, and it is not an Emerson-Clarke path quantifier. The grandfather case is \(\forall o.\, \neg\mathrm{Fix}\). The note in the coat is two distinct states that both satisfy Fix. Either refutes Process.

3. The two literatures

Temporal logic began as tense. Prior's operators formalized before and after [1]. Kamp added until and since. Pnueli proposed linear temporal logic for programs [2]. Emerson and Clarke gave the branching version, with path quantifiers over a computation tree [3]. The formula above uses none of those path quantifiers. Exists-unique is a first-order condition on one transition. Calling it temporal records what the transition is: the story after the return must agree with the story that was sent.

The other literature asks which stories are kept. Dummett treated the ban as a rule of English [4]. Black and Horwich asked what happens to the person who tries to stop the later event [5]. Lewis split can into a local and a global reading [6]. Faye still treats the paradoxes as unresolved [7]. Godel gave a rotating dust solution with a closed curve through every event [8]. Morris, Thorne and Yurtsever made a wormhole into a time machine if the averaged null energy condition fails [9]. Friedman and collaborators state Novikov's principle [10]. The billiard has one continuation, two, or none [11]. Carlini, Frolov, Mensky, Novikov and H. H. Soleng derived a version from the action [12]. Earman: a selection rule is not a dynamics [13].

Deutsch asks for a fixed point of a state on the curve [14]. Aaronson and Watrous put the power at PSPACE [15]. Bennett, Leung, Smith and Smolin object to the preparation [16]. Tolksdorf and Verch mimic the condition with no curve [17]. Lloyd and Maccone post-select the matching runs [18]. Oreshkov, Costa and Brukner write a channel from outputs to inputs with no assumed order [19]. The process function is the deterministic skeleton of that idea [20]. Araujo, Feix, Navascues and Brukner extend the Lugano function [21]. Routed quantum circuits are Vanrietvelde, Kristjansson and Barrett; Ormrod is not an author [22]. Ori's dust shell develops closed curves from a regular slice; it is not this formula [23]. Daher Ahmed and Kunjwal give two sufficient conditions that are not used here [24].

4. The open shuffle

Add a source \(e\) and store the sent string.

\[ U(o,e) = (w(o)\oplus e,\, o), \qquad U^{-1}(i,s) = (s,\, w(s)\oplus i). \]

Both compositions are the identity because \(a\oplus(a\oplus b)=b\). This holds for every \(w\), including the copy rule. Recovery of \(w\) at source 0 is not uniqueness of the fixed point. The Lean file records both compositions. A metric is not used. XOR is addition modulo 2, not a displacement along a curve.

5. The closed step

Feeding the output back in, against the identity intervention, asks which strings equal their image. For the copy rule every string does. On three bits the filter has length 8. Unique finish is what removes the extra count: if two strings differ, some party sent different bits and received the same bit, and that party is a zero factor in the closed contraction. The gram cancellation is the content of the longer essay. It is not a theorem of the temporal file. The temporal file proves the empty preimage, the double preimage, both compositions of the shuffle, and the eight-count.

6. What is not claimed

No Einstein metric for the three-bit example. No CTL path quantifier. The open shuffle is not the closed contraction. The closed contraction is not an isometry for every rule.
